Class Invariant Protection

Encapsulation ensures an object's internal representation cannot be modified into an invalid state. In StayFinder, all raw state variables are declared strictly private. Callers cannot modify booking dates, calculated prices, or status strings directly.

RESOURCE MANAGEMENT & OBJECT LIFECYCLES

RAII, Constructors & Virtual Destructors

1. Resource Acquisition Is Initialization (RAII)

In Database, the SQLite connection handle is tied to the C++ object lifecycle. The connection is opened in the constructor and guaranteed to be closed in the destructor (sqlite3_close(db_)), even if exceptions are thrown during query execution.

backend/database.h (RAII Pattern) 
class Database {
public:
    explicit Database(const std::string& path);
    ~Database() { if (db_) sqlite3_close(db_); } // Guaranteed cleanup

    // Deleted copy semantics prevent double-close
    Database(const Database&) = delete;
    Database& operator=(const Database&) = delete;
private:
    sqlite3* db_ = nullptr;
};

2. Critical Need for Virtual Destructors

Both User and PricingStrategy declare virtual ~Base() = default;. Without a virtual destructor, deleting a derived instance through a base pointer causes undefined behavior and prevents derived destructors from running.
